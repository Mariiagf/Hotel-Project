# Hotel Reservation Database Project

## Overview

This project focuses on the design, implementation and comparison of different database systems for a hotel complex located in Santiago de Compostela, Spain.

The database manages the main information required for hotel operations, including hotels, customers, employees, rooms, reservations, reviews, hotel locations and nearby points of interest.

The main goal is to explore how different database technologies store, organize and retrieve the same information, while comparing their performance, scalability and characteristics.

## Objectives

- Design a database model for a hotel reservation system.
- Manage hotel-related information and relationships between entities.
- Implement the same data domain using different database technologies.
- Execute queries and transactions across the different implementations.
- Compare query performance, scalability and storage approaches.
- Identify the advantages and disadvantages of each database model.

## Database Technologies

The project explores and compares the following database approaches:

- **Relational databases:** structured data organized into tables and relationships.
- **Aggregated and compound data types:** alternative relational data organization.
- **JSON databases:** document-oriented data representation using JSON.
- **Distributed relational databases (Citus):** relational data distributed across multiple nodes.
- **MongoDB:** document-oriented NoSQL database.
- **Neo4j:** graph database focused on relationships between data.
- **HBase:** column-family NoSQL database.

## Data Model

The system covers the following main entities:

- Hotels
- Customers
- Employees
- Rooms
- Reservations
- Reviews
- Hotel locations
- Nearby points of interest

These entities represent the core information needed to manage a hotel complex and its reservation operations.

## Comparison and Analysis

The different implementations are evaluated by considering:

- Data storage and organization.
- Query execution and performance.
- Transaction management.
- Scalability and distributed data management.
- Advantages and disadvantages of each database technology.

## Project Scope

This is a database-focused project that studies how different database models can represent and manage the same hotel reservation environment. It provides a practical comparison between traditional relational systems and several NoSQL and distributed database solutions.

## Location
